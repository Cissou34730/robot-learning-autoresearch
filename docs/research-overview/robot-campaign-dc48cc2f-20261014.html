3. Fewer repairs did not prove correct code

The campaign made seven coding calls. They covered five distinct completed assignments, one interrupted attempt and one source repair.

AssignmentWhat happened
Full-range trainingThe source and proposed check worked without a recorded correction.

Hold diagnosticsThe first attempt did not return normally. A new attempt completed. A wrong check invocation failed before corrected arguments worked.
Hold rewardThe source worked after the PI corrected the proposed check arguments.

The checker expected the wrong answer

The coder wrote a small script to check the comparison analysis.

Its artificial targets were at 6, 10, 14, 17 and 20 cm.

The group from 6 cm to less than 10 cm contained one failed case.

The correct result was one case and zero successes. The checker expected two cases and one success.

Correct analysis code therefore failed the check. The campaign repaired this checker.

The angle error did not cause an exception

The code calculated joint angles for each target.

Some calculated angles fell outside the joint limits. An equivalent angle for the same pose fell inside the limits.

The code did not choose that valid angle before it calculated the limit margin.

It could report a valid target pose as outside the joint limits.

The checks missed this error. It remained in the campaign's final diagnostic source.

The official pass remains valid. The wrong target-angle margin was a diagnostic value. It did not determine official success.

But it weakened explanations about which target poses the joint limits blocked.

The error concerns calculated target angles. It does not justify changes to measured joint positions.

Other recorded code problems

Five of six completed coder reports included a module name or a complete invocation inside the check arguments.

Runner already selects the module. The arguments must contain only separate flags and values.

The PI corrected several proposals before execution. One proposal reached Runner unchanged and stopped M7.

Two of eleven attempted measurements failed. Nine completed. Failed operations record execution history, not scientific evidence.

The interrupted coding attempt recorded a wait of about four hours. The runtime warned that a response did not arrive within 1,800 seconds.

This does not show four hours of active model work. The cause of the long wait remains unknown.

The maintainer selected GPT-6 Luna with max reasoning.

The reviewer receives the original request, actual changes and proposed checks.

The PI decides corrections through the original coder. The reviewer does not edit code or approve science.

Reviewer usage has a separate record. Commit 4e2c84d contains this change.

A later SDK check read two files with verified Luna/max and used 0.087176 AIU. This small check does not predict campaign review costs.

The new reviewer was not part of this campaign. Its effect on later campaign code remains to be measured.

6. What remains uncertain

  • The policy passed exactly at the required score. The 200 cases do not prove success on every future target.
  • The final development panel still had one no-entry failure and one failed hold.
  • The tested transfer used one training seed. This report does not establish repeatability across seeds.
  • Large actions during the hold remained a recorded concern. The final score does not explain that behavior.
  • The comparisons support complete-model performance. They do not isolate why the changes worked.
  • The target-angle error weakens part of the geometry analysis. A policy pass does not remove that code defect.
Terms in this report
Policy
The learned controller that selects the robot's actions.
Checkpoint
A saved policy from one point during training.
Episode or case
One attempt to reach a target and complete the hold.
Matched test
A test in which two policies face the same cases.
Inquiry
A recorded scientific question with a result at closure.
Code check
A script that compares code outputs with expected results.
Limit margin
The distance between a joint angle and the nearest joint limit.
Silent error
Code that runs but calculates or reports a wrong value.
